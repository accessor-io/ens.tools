      Encryption Setup Guide

      This application now uses encryption for all user data stored in the database and localStorage.

      Overview

      Client-Side Encryption

    99. Location: Browser localStorage
    100. Algorithm: AES-256 via crypto-js
    101. Key Derivation: User address + session secret
    102. Auto-migration: Automatically migrates unencrypted data to encrypted format

      103. Server-Side Encryption

    103. Location: PostgreSQL database (user_configs table)
    104. Algorithm: AES-256-GCM (via Node.js crypto)
    105. Key Derivation: User address + environment key
    106. Format: Base64-encoded encrypted strings
