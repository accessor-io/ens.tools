ENS Action Schema System - Complete Guide

Overview

The ENS Action Schema System allows you to define, batch, and execute multiple ENS protocol operations using a simple bracket notation syntax. This system enables you to:

  • Define custom action sequences using bracket notation
  • Batch multiple actions into a single transaction (saving gas)
  • Upload and execute action files
  • Track all actions in the audit log with highlighted call data

      9. Bracket Notation Syntax

      Basic Format

      [operator]action: [value1]@parameter1@[value2]@parameter2

      Operators

    9. + - Add/create operation (e.g., +mintSubdomain, +delegateTo)
    10. - - Remove/delete operation (e.g., -removeSubdomain, -removeDelegate)
    11. = or no prefix - Set/update operation (e.g., setText, setAddr)

      12. Parameter Format

      Parameters use the format: [value]@parameterName
    12. Values are wrapped in square brackets [value]
    13. Parameter names follow after @
    14. Multiple parameters are separated by @

      15. Examples

      # Create subdomain
+mintSubdomain: [app]@subname@[example.eth]@parent


      Set text record
      
setText: [example.eth]@domain@[description]@key = [My awesome domain]@value


      Remove delegate
      
-removeDelegate: [example.eth]@domain@[0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@delegate


      Delegate with permissions
      
+delegateTo: [example.eth]@domain = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@delegate@[7]@permissions

      Available Actions

      Domain Operations

      Action Operator Description Example
      transfer = Transfer domain ownership transfer: [example.eth]@domain = [0x742d...]@to
      wrap + Wrap domain in NameWrapper +wrap: [example.eth]@domain = [0x742d...]@owner
      unwrap - Unwrap domain from NameWrapper -unwrap: [example.eth]@domain = [0x742d...]@controller
      renew + Renew domain registration +renew: [example.eth]@domain + [31536000]@duration

      Subdomain Operations

      Action Operator Description Example
      mintSubdomain + Create subdomain +mintSubdomain: [app]@subname@[example.eth]@parent
      removeSubdomain - Remove subdomain -removeSubdomain: [app]@subname@[example.eth]@parent
      transferSubdomain = Transfer subdomain ownership transferSubdomain: [app]@subname@[example.eth]@parent = [0x742d...]@to

      Record Operations

      Action Operator Description Example
      setAddr = Set address record setAddr: [example.eth]@domain = [0x742d...]@address
      setText = Set text record setText: [example.eth]@domain@[description]@key = [My domain]@value
      removeText - Remove text record -removeText: [example.eth]@domain@[description]@key
      setContentHash = Set content hash setContentHash: [example.eth]@domain = [/ipfs/Qm...]@contentHash
      setTTL = Set TTL setTTL: [example.eth]@domain = [3600]@ttl
      setABI = Set ABI record setABI: [example.eth]@domain@[1]@contentType = [{"type":"function"}]@data
      setResolver = Set resolver setResolver: [example.eth]@domain = [0x231b...]@resolver

      Delegation Operations

      Action Operator Description Example
      delegateTo + Add delegate +delegateTo: [example.eth]@domain = [0x742d...]@delegate@[7]@permissions
      delegateAuthSelect = Set delegate permissions delegateAuthSelect: [example.eth]@domain@[0x742d...]@delegate = [MANAGE_SUBDOMAINS,SET_TEXT_RECORD]@permissionKeys
      removeDelegate - Remove delegate -removeDelegate: [example.eth]@domain@[0x742d...]@delegate
      updateDelegate = Update delegate updateDelegate: [example.eth]@domain@[0x742d...]@delegate = [15]@permissions@[1735689600]@expiresAt
      lockDelegate = Lock delegate lockDelegate: [example.eth]@domain@[0x742d...]@delegate
      unlockDelegate = Unlock delegate unlockDelegate: [example.eth]@domain@[0x742d...]@delegate

      Permission Keys

      For delegation operations, use these permission keys:
    15. MANAGE_SUBDOMAINS - Create and manage subdomains
    16. SET_ADDR_RECORD - Set address records
    17. SET_TEXT_RECORD - Set text records
    18. SET_CONTENT_HASH - Set content hash
    19. SET_PUBKEY - Set public key
    20. SET_ABI - Set ABI
    21. SET_ZONEHASH - Set zone hash
    22. SET_TTL - Set TTL
    23. SET_RESOLVER - Set resolver
    24. SET_OWNER - Set owner
    25. SET_FUSES - Set fuses

      26. Creating Action Files

      Step 1: Write Your Actions

      Create a text file with your actions, one per line: 
      # My ENS Actions
+mintSubdomain: [app]@subname@[example.eth]@parent = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@owner
setText: [example.eth]@domain@[description]@key = [My awesome domain]@value
setText: [example.eth]@domain@[url]@key = [https://example.com]@value
+delegateTo: [example.eth]@domain = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@delegate@[7]@permissions

      Step 2: Save Your File

      Save as .txt or .ens file (e.g., my-actions.txt)

      Step 3: Upload and Execute

    26. Navigate to the Action Schema interface
    27. Click "Upload Actions" or paste your actions
    28. Review the parsed actions
    29. Click "Execute Batch Transaction"
    30. Confirm the transaction in your wallet

      31. Using Templates

      Templates allow you to reuse action patterns across multiple domains.

      Template Variables

      Use {{variable}} syntax for placeholders: 
      setText: [{{domain}}]@domain@[{{key}}]@key = [{{value}}]@value

      Pre-built Templates

      The system includes several pre-built templates:
    31. Setup New Domain - Complete domain setup with metadata
    32. Batch Metadata Update - Update multiple text records
    33. Create Subdomain Structure - Create multiple subdomains
    34. Delegate Permissions - Set up delegation
    35. Wrap and Configure - Wrap domain and set fuses

      36. Using a Template

    36. Select a template
    37. Enter your domains
    38. Fill in variable values
    39. Generate and execute

      40. Batch Transactions

      How Batching Works

      Multiple actions are bundled into a single Multicall3 transaction:
    40. Each action is converted to calldata
    41. All calldata is combined into one batch call
    42. Single transaction executes all actions
    43. Gas savings: ~21,000 gas per additional action

      44. Gas Estimation

      The system automatically estimates gas for batch transactions. Typical costs:
    44. Single action: ~50,000 - 100,000 gas
    45. Batch (2-5 actions): ~100,000 - 300,000 gas
    46. Batch (6-10 actions): ~300,000 - 500,000 gas

      47. Transaction Fees

      All actions in a batch share a single transaction fee, significantly reducing costs compared to individual transactions.

      Audit Log Integration

      Automatic Logging

      All batch transactions are automatically logged in the audit log with:
    47. Transaction hash
    48. Total number of actions
    49. Individual action details
    50. Highlighted call data for each action

      51. Viewing Batch Actions

    51. Navigate to Audit Log
    52. Find your batch transaction entry
    53. Click to expand
    54. View individual actions in dropdown
    55. See highlighted call data for each action

      56. Call Data Highlighting

      Each action shows:
    56. Full batch call data
    57. Highlighted portion relevant to that action
    58. Contract address
    59. Function name
    60. Function arguments

      61. Best Practices

      1. Organize Actions Logically

      Group related actions together: 
      # Domain Setup
setResolver: [example.eth]@domain = [0x231b0Ee14048e9dCcD1d247744d114a4EB5E8E63]@resolver
setAddr: [example.eth]@domain = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@address


      Metadata
      
setText: [example.eth]@domain@[description]@key = [My domain]@value
setText: [example.eth]@domain@[url]@key = [https://example.com]@value


      Subdomains
      
+mintSubdomain: [app]@subname@[example.eth]@parent
+mintSubdomain: [api]@subname@[example.eth]@parent

      2. Use Comments

      Add comments to document your actions: 
      # Setup main domain
setResolver: [example.eth]@domain = [0x231b...]@resolver


      Add metadata
      
setText: [example.eth]@domain@[description]@key = [My domain]@value

      3. Validate Before Execution

      Always review parsed actions before executing:
    61. Check domain names are correct
    62. Verify addresses are valid
    63. Confirm parameter values

      64. 4. Test with Small Batches First

      Start with 2-3 actions to test, then scale up.

      5. Keep Action Files Version Controlled

      Save your action files in version control for:
    64. Reproducibility
    65. Documentation
    66. Rollback capability

      67. 6. Use Templates for Repetitive Tasks

      Create templates for common operations to save time.

      Examples

setText: [example.eth]@domain@[url]@key = [https://example.com]@value
setText: [example.eth]@domain@[avatar]@key = [https://example.com/avatar.png]@value

setText: [example.eth]@domain@[com.github]@key = [example]@value

      Example 2: Subdomain Structure

      # Create subdomains
+mintSubdomain: [app]@subname@[example.eth]@parent = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@owner
+mintSubdomain: [api]@subname@[example.eth]@parent = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@owner
+mintSubdomain: [www]@subname@[example.eth]@parent = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@owner
+mintSubdomain: [dao]@subname@[example.eth]@parent = [0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@owner


      Configure subdomains
      
setText: [app.example.eth]@domain@[description]@key = [Main application]@value
setText: [api.example.eth]@domain@[description]@key = [API endpoint]@value

      Example 3: Delegation Setup

      # Add delegate with specific permissions

      Or use permission keys
      
delegateAuthSelect: [example.eth]@domain@[0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb]@delegate = [MANAGE_SUBDOMAINS,SET_TEXT_RECORD,SET_ADDR_RECORD]@permissionKeys

      Troubleshooting

      Common Errors

    67. Invalid action format
      68. - Check bracket notation syntax - Ensure all parameters are provided - Verify operator usage
    68. Missing required parameters
      69. - Review action schema for required fields - Check parameter names match exactly
    69. Transaction fails
      70. - Verify you have permissions for all actions - Check domain ownership - Ensure sufficient gas
    70. Call data not highlighting
      71. - This is normal for some complex actions - Full call data is always available
