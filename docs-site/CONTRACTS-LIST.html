Custom Smart Contracts

FeeCollection.sol

  • Location: contracts/FeeCollection.sol
  • Solidity Version: ^0.8.20
  • License: MIT
  • Status: Not yet deployed (placeholder address: 0x0000000000000000000000000000000000000000)
  • Service Integration: src/lib/services/fee-collection-service.ts

    • Purpose

    Collects fees for contract registrations, ENS name registrations, subdomain creation, domain transfers, and marketplace transactions. Allows admin-controlled fee withdrawal and fee rate management.

    Key Features

  • Registration fee collection for contract registrations
  • Name registration fee collection for ENS name registrations
  • Subdomain creation fee collection
  • Transfer fee collection for domain transfers
  • Marketplace fee collection (configurable basis points, max 10%)
  • Admin-controlled fee withdrawal
  • Fee rate management (admin can update fees)
  • Separate tracking for each fee type
  • Event emission for all fee transactions

    • Functions

    Public/External Functions:
  • payRegistrationFee(address registrant, address contractAddress, string ensName) - Pay fee for contract registration
  • payNameRegistrationFee(address registrant, string ensName) - Pay fee for ENS name registration
  • paySubdomainCreationFee(address creator, string parentName, string subdomainLabel) - Pay fee for subdomain creation
  • payTransferFee(address from, address to, string ensName) - Pay fee for domain transfer
  • payMarketplaceFee(address seller, address buyer, address tokenAddress, uint256 tokenId, uint256 salePrice) - Record marketplace fee payment
  • calculateMarketplaceFee(uint256 salePrice) - Calculate marketplace fee from sale price
  • getTotalFees() - Get total fees collected across all types
  • getAvailableBalance() - Get available balance for withdrawal
  • getRegistrationFees() - Get total registration fees collected
  • getNameRegistrationFees() - Get total name registration fees collected
  • getSubdomainCreationFees() - Get total subdomain creation fees collected
  • getTransferFees() - Get total transfer fees collected
  • getMarketplaceFees() - Get total marketplace fees collected
    • Admin-Only Functions:
  • withdrawFees(uint256 amount, address recipient) - Withdraw collected fees
  • setRegistrationFee(uint256 newFee) - Update registration fee
  • setNameRegistrationFee(uint256 newFee) - Update name registration fee
  • setSubdomainCreationFee(uint256 newFee) - Update subdomain creation fee
  • setTransferFee(uint256 newFee) - Update transfer fee
  • setMarketplaceFee(uint256 newFeeBps) - Update marketplace fee rate (max 1000 = 10%)
  • transferAdmin(address newAdmin) - Transfer admin role

    • State Variables

  • admin - Admin address (set in constructor)
  • registrationFee - Fee for contract registration
  • nameRegistrationFee - Fee for ENS name registration
  • subdomainCreationFee - Fee for subdomain creation
  • transferFee - Fee for domain transfer
  • marketplaceFeeBps - Marketplace fee in basis points (e.g., 250 = 2.5%)
  • totalFeesCollected - Total fees collected across all types
  • registrationFeesCollected - Total registration fees
  • nameRegistrationFeesCollected - Total name registration fees
  • subdomainCreationFeesCollected - Total subdomain creation fees
  • transferFeesCollected - Total transfer fees
  • marketplaceFeesCollected - Total marketplace fees

    • Events

  • RegistrationFeePaid(address indexed registrant, address indexed contractAddress, string ensName, uint256 amount)
  • NameRegistrationFeePaid(address indexed registrant, string ensName, uint256 amount)
  • SubdomainCreationFeePaid(address indexed creator, string parentName, string subdomainLabel, string fullName, uint256 amount)
  • TransferFeePaid(address indexed from, address indexed to, string ensName, uint256 amount)
  • MarketplaceFeePaid(address indexed seller, address indexed buyer, address indexed tokenAddress, uint256 tokenId, uint256 salePrice, uint256 feeAmount)
  • FeesWithdrawn(address indexed recipient, uint256 amount)
  • RegistrationFeeUpdated(uint256 oldFee, uint256 newFee)
  • MarketplaceFeeUpdated(uint256 oldFeeBps, uint256 newFeeBps)

    • Default Fees (in service configuration)

  • Registration Fee: 0.01 ETH
  • Name Registration Fee: 0.005 ETH
  • Subdomain Creation Fee: 0.003 ETH
  • Transfer Fee: 0.002 ETH
  • Marketplace Fee: 250 basis points (2.5%)

    • Integration Points

  • src/lib/services/fee-collection-service.ts - Main service for interacting with contract
  • src/components/admin/FeeManagement.tsx - Admin UI for fee management
  • src/components/workflows/ContractRegistration.tsx - Uses fee service during registration
  • src/lib/ens/register-name.ts - Uses fee service for name registration
  • src/lib/ens/ens-write-operations.ts - Uses fee service for subdomain creation
  • src/lib/ens/transfer-domain.ts - Uses fee service for domain transfers
  • src/lib/services/ens-marketplace-service.ts - Uses fee service for marketplace fees
  • src/components/fees/FeePreview.tsx - Fee estimation UI
  • src/components/fees/FeeHistory.tsx - Fee history display

    • Deployment Notes

  • Contract address must be configured in feeCollectionService instance
  • Admin address must be set during deployment
  • All fees are set in constructor but can be updated by admin
  • Marketplace fee is capped at 10% (1000 basis points)
  • Contract accepts ETH via receive() fallback function

      Granular Permission System Contracts

      The granular permission system enables fine-grained, time-bound delegation of ENS domain operations. This system implements the ENSIP GNA (Granular Name Assignment) specification.

      Core Contracts:
    2. ENSNamingDelegateGranular - Central policy repository for delegation rules
    3. GranularResolver - ENS resolver that enforces granular permissions
      4. Interface Contracts:
    4. IENSRegistry.sol - ENS Registry interface
    5. INameWrapper.sol - NameWrapper interface
    6. IENSResolver.sol - ENS Resolver interface
    7. IGranularAssignmentController.sol - GNA controller interface

      8. Implemented (Ready for Deployment)

    8. ENSNamingDelegateGranular - Granular permission delegation contract

      9. - Status: Code complete, ready to deploy - Location: contracts/ENSNamingDelegateGranular.sol - Purpose: Fine-grained, time-bound permission delegation for ENS domains - Key Features: - 11 granular permission types (bitmask-based) - Time-bound delegations with expiration - Whitelist/blacklist support - Emergency pause and revoke functions - Lock/unlock delegates - Maximum delegation duration limits - Permission Types: - MANAGE_SUBDOMAINS (1) - Create and manage subdomains - SET_ADDR_RECORD (2) - Set address records - SET_TEXT_RECORD (4) - Set text records - SET_CONTENT_HASH (8) - Set content hash - SET_PUBKEY (16) - Set public key - SET_ABI (32) - Set ABI data - SET_ZONEHASH (64) - Set zone hash - SET_TTL (128) - Set TTL - SET_RESOLVER (256) - Set resolver - SET_OWNER (512) - Set owner (Registry operations) - SET_FUSES (1024) - Set fuses (NameWrapper operations) - Integration: Hardcoded mainnet ENS Registry and NameWrapper addresses - Security: ReentrancyGuard, Pausable, comprehensive access controls

    9. GranularResolver - ENS Resolver with granular permission enforcement

      10. - Status: Code complete, ready to deploy - Location: contracts/GranularResolver.sol - Purpose: ENS resolver that enforces granular permissions from ENSNamingDelegateGranular - Key Features: - Full ENS resolver interface compliance (EIP-137, EIP-165, EIP-205, etc.) - Permission enforcement for all resolver operations - Owner override toggle (optional bypass) - Integration with ENSNamingDelegateGranular for authorization - Deployment: Requires ENSNamingDelegateGranular address in constructor - Compatibility: Full EIP compliance for all ENS resolver functions

      Required But Not Yet Deployed
