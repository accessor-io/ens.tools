Revenue Breakdown Document - config

Document Version: 1.0 Date: January 2025 Status: Production Ready Last Updated: 2025-01-XX

Executive Summary

config generates revenue through a dual-fee model: fixed fees for operations and variable marketplace fees on sales. The platform is designed to capture value from ENS domain management, contract registrations, and marketplace transactions, with special handling for premium name sales where proceeds go to ENS DAO.

Key Revenue Metrics:
  • Year 1 Estimate (Moderate): $100,000-150,000
  • Primary Revenue Driver: Marketplace fees (2.5% of sales)
  • High-Value Opportunity: Premium name sales
  • Steady Income: Fixed operation fees

      11. Fee Structure

      Fixed Fees (Per Transaction)

      All fixed fees are denominated in ETH and collected via the FeeCollection smart contract.

      Fee Type Amount (ETH) USD Equivalent* Collection Point
      Contract Registration 0.01 ETH $25-30 Before contract registration
      ENS Name Registration 0.005 ETH $12-15 Before name registration
      Subdomain Creation 0.003 ETH $7-9 Before subdomain creation
      Domain Transfer 0.002 ETH $5-6 Before domain transfer

      *USD equivalent assumes ETH price of $2,500

      Variable Fees (Percentage-Based)

      Fee Type Rate Collection Method Special Rules
      Marketplace Fee 2.5% (250 bps) Seaport consideration items Applied to all sales
      Premium Name Sales 2.5% (250 bps) Seaport consideration items Full proceeds → ENS DAO, fee → config
      Marketplace Fee Details:
    11. Regular Names: Seller receives 97.5%, config receives 2.5%
    12. Premium Names: ENS DAO receives 97.5%, config receives 2.5%
    13. Maximum Fee: 10% (1,000 basis points) - contract enforced
    14. Default Rate: 2.5% (250 basis points)

      15. Revenue Streams

      Stream 1: Fixed Operation Fees

      Description: Fees collected for platform operations (registrations, transfers, etc.) Revenue Characteristics:
    15. Predictable and recurring
    16. Scales linearly with user adoption
    17. Lower per-transaction value but consistent
    18. Not dependent on market conditions
      19. Collection Mechanism:
    19. Fees paid before operation execution
    20. Collected via FeeCollection contract
    21. Tracked separately by fee type
    22. Admin can withdraw collected fees
      23. Monthly Revenue Potential:
    23. Low: $2,000-2,400 (80 transactions)
    24. Moderate: $8,750-10,500 (350 transactions)
    25. High: $35,000-42,000 (1,400 transactions)

      26. Stream 2: Marketplace Fees (Regular Names)

      Description: 2.5% fee on all regular ENS domain sales Revenue Characteristics:
    26. Variable based on sales volume
    27. Scales with marketplace activity
    28. Higher per-transaction value
    29. Dependent on market conditions
      30. Collection Mechanism:
    30. Fee included in Seaport order consideration items
    31. Automatically routed to FeeCollection contract
    32. Recorded via recordMarketplaceFee() function
    33. Tracked in marketplaceFeesCollected counter
      34. Monthly Revenue Potential:
    34. Low: $250 ($10k volume)
    35. Moderate: $1,250 ($50k volume)
    36. High: $5,000 ($200k volume)

      37. Stream 3: Marketplace Fees (Premium Names)

      Description: 2.5% fee on premium name sales (proceeds go to ENS DAO) Revenue Characteristics:
    37. Highest per-transaction value
    38. Premium names sell for 10-100+ ETH
    39. Limited supply but high value
    40. Significant revenue impact from single sales
      41. Collection Mechanism:
    41. Same as regular marketplace fees
    42. Premium detection via premiumPriceService
    43. Seller payment routed to ENS DAO treasury
    44. Fee routed to FeeCollection contract
      45. Monthly Revenue Potential:
    45. Low: $125 ($5k premium sales)
    46. Moderate: $625 ($25k premium sales)

      217. Marketplace Fee Collection Flow

    217. User creates listing via createDomainListing()

      219. - Seller receives: 97.5% of sale price - FeeCollection contract receives: 2.5% of sale price

    219. Order fulfilled via Seaport
    220. Fee automatically sent to contract
    221. recordMarketplaceFee() called to update tracking
      222. For Premium Names:
    222. User creates listing via createDomainListing()
    223. System detects premium name via premiumPriceService
    224. Seaport order created with consideration items:

      225. - ENS DAO treasury receives: 97.5% of sale price - FeeCollection contract receives: 2.5% of sale price

    225. Order fulfilled via Seaport
    226. Fee automatically sent to contract
    227. recordMarketplaceFee() called to update tracking
