Marketplace Implementation - OpenSea Seaport Integration

Overview

ens.tools now includes a marketplace component that integrates with OpenSea's Seaport protocol for buying and selling NFTs and ENS domains.

What Was Implemented

1. OpenSea Marketplace Service (src/lib/services/opensea-marketplace-service.ts)

A service layer that provides integration with OpenSea's Seaport protocol, including:

Core Features:

  • Seaport Contract Integration: Full ABI definitions for Seaport v1.5 contracts
  • Listing Management: Fetch and display active NFT listings
  • Offer Management: View and track marketplace offers
  • ENS Domain Support: Browse ENS domains listed on OpenSea
  • Collection Statistics: Real-time collection metrics (floor price, volume, sales)
  • Marketplace Approval: Approve Seaport to trade tokens on behalf of users

    • Seaport Functions Implemented:

  • fulfillBasicOrder() - Execute simple buy/sell orders
  • fulfillOrder() - Execute complex orders with multiple items
  • getOrderStatus() - Check order validation and fill status
  • matchOrders() - Match multiple orders for atomic swaps

    • Marketplaces Supported:

  • OpenSea (primary)
  • Seaport-compatible marketplaces
  • Cross-chain support (Ethereum, Optimism, Base, Arbitrum)

    • 2. Marketplace Component (src/components/marketplace/Marketplace.tsx)

    A UI component providing marketplace functionality:

    Key Features:

    Search & Discovery
  • Search by token contract address
  • View listings, offers, and statistics
  • Browse ENS domain listings
    • Tabs:
    1. Listings - Active NFT listings for sale
    2. Offers - Pending offers from buyers
    3. ENS Domains - Specialized ENS domain marketplace
    4. Statistics - Collection analytics and metrics
      5. Trading Actions:
    5. View listing details
    6. Approve marketplace for trading
    7. Approve for all tokens in a collection
    8. Buy NFTs directly from listings
      9. Wallet Integration:
    9. Connect wallet for trading
    10. Transaction signing and submission
    11. Real-time approval status

      15. Technical Details

      Seaport Protocol

      Seaport is OpenSea's open-source marketplace protocol:

    15. Decentralized: Non-custodial trading
    16. Gas Efficient: Batch orders and fulfillments
    17. Composable: Supports complex order types
    18. Secure: Order validation and signature verification

      19. Contract Addresses

      Seaport v1.5 is deployed at:

    19. Mainnet: 0x00000000000000ADc04C56Bf30aC9d3c0aAF14dC
    20. Sepolia: 0x00000000000000ADc04C56Bf30aC9d3c0aAF14dC
    21. Optimism: 0x00000000000000ADc04C56Bf30aC9d3c0aAF14dC
    22. Base: 0x00000000000000ADc04C56Bf30aC9d3c0aAF14dC
    23. Arbitrum: 0x00000000000000ADc04C56Bf30aC9d3c0aAF14dC

      24. API Integration

      The service integrates with OpenSea's API v2:

    24. Listings endpoint: /chain/{chain}/contract/{address}/listings
    25. Offers endpoint: /chain/{chain}/contract/{address}/offers
    26. Stats endpoint: /chain/{chain}/contract/{address}/stats
    27. ENS collection: /chain/{chain}/collection/ens

      28. Authentication

      VITE_OPENSEA_API_KEY=your_api_key_here

      Usage

      Accessing the Marketplace

    28. Navigate to "Marketplace" in the sidebar
    29. Connect your wallet
    30. Search for a token contract address
    31. Browse listings, offers, and statistics

      32. Trading Process

    32. Approve Marketplace:
      33. - Click "Approve for All" to allow Seaport to trade tokens - Or approve individual tokens when making purchases
    33. Buy NFTs:
      34. - Browse active listings - Click "Buy" on desired NFT - Confirm transaction in wallet - Wait for on-chain confirmation
    34. View Offers:
      35. - Check "Offers" tab for pending offers - Review offer details and pricing
    35. ENS Domains:
      36. - Click "ENS Domains" tab - Browse available ENS domain listings - Purchase domains directly from marketplace

      Collection Statistics

      The Statistics tab provides:
    36. Floor Price: Lowest listed price
    37. Total Volume: All-time trading volume
    38. Owners: Unique holder count
    39. Listed Count: Currently listed items
    40. Average Price: Mean sale price
    41. Total Sales: Number of completed transactions

      42. Error Handling

      The service includes fallback mechanisms:
    42. API errors fall back to mock data for development
    43. Transaction errors display user-friendly messages
    44. Wallet connection required for trading actions
    45. Network switching supported for multi-chain trading

      46. Security Considerations

    46. Approval Management: Users must explicitly approve Seaport to trade tokens
    47. Signature Verification: Seaport validates all order signatures
    48. Non-Custodial: Never holds user funds or tokens
    49. Transaction Safety: All transactions require explicit user confirmation
